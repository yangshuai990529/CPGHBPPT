# Background Analysis

Version: 1.0.0

## Purpose
形成可支持 Why Now 的背景链。
## When to Use
需要解释启动产品决策的外部或内部变化。
## When NOT to Use
不用于堆砌行业历史或替代市场研究。
## Input
主题、时间范围、变化证据、当前问题、决策触发。
## Reasoning Process
区分长期背景与近期变化；验证 Change；连接 Problem；说明不行动影响和决策窗口。
## Output
背景主张、变化、问题、机会提示和证据缺口。
## Output Schema
`{"context":"","change":"","problem":"","why_now":"","evidence_refs":[],"gaps":[]}`
## Quality Criteria
Why Now 有时间触发；背景与产品决策直接相关。
## Common Mistakes
把趋势口号当证据；没有说明为何是现在。
## Example
“AI 普及”不足；应说明目标用户行为或技术成本在何时发生了什么变化，以及它如何影响当前产品。
