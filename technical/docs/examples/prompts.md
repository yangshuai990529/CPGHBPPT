# 可复制的需求示例

- `/CPGHBPPT 做 AI Picture 产品概要，重点比较 Samsung Sony Hisense 官网可核验的能力。缺少用户与内部证据时不要生成既定 TCL 策略。`
- `/CPGHBPPT 基于 input/NPS.pdf 做用户洞察讨论稿；优先保留原文、标出缺失的样本与口径。`
- `/CPGHBPPT 我已写好内容，不要 Research，不要改写，只按照公司模板排版。文件在 input/content.md。`

在 Codex 中 `/CPGHBPPT` 是本项目约定的提示前缀；若宿主不识别自定义斜杠命令，直接输入正文或使用项目 Skill。CLI 可以运行 `./CPGHBPPT build --topic "..." --input input/NPS.pdf`。
