# Repository publication and privacy rules

This project is prepared for the public repository `yangshuai990529/CPGHBPPT`. The repository owner explicitly approved public visibility and inclusion of `PPT设计规范/产品PPT模板.pptx`.

The public repository must not contain historic PPT/PDF libraries, user input, generated projects, cache, local review records, personal knowledge, credentials, environment files or machine-specific logs. These remain under ignored paths such as `workspace/`, `projects/`, `output/`, `cache/` and `input/`. Review the staged file list and secret scan before every publication; `.gitignore` cannot protect a file that is already tracked.

`./setup.sh` copies the published source template to the ignored runtime path `templates/tcl-product/master.pptx`. Source-code MIT licensing does not relicense that template, company trademarks, or third-party visual assets; see `NOTICE.md`.
