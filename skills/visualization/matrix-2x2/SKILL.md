# Matrix 2x2
Version: 1.0.0
## Purpose
展示对象在两个关键维度上的定位和空白。
## When to Use
两个轴独立、可定义、可给出位置依据。
## When NOT to Use
轴主观、对象位置无证据、第三维决定结论。
## Input
轴定义、范围、对象坐标/等级、Source、象限含义。
## Reasoning Process
验证轴独立；定义标尺；定位对象；检查位置不确定性；谨慎解释空白。
## Output
2×2 规格。
## Output Schema
`{"type":"matrix-2x2","x_axis":{},"y_axis":{},"items":[],"quadrants":[],"source_ids":[]}`
## Quality Criteria
轴端点清楚；位置可追溯；不把空白自动称蓝海。
## Common Mistakes
先定结论再造轴；用 Logo 大小暗示第三变量。
## Example
可按“自动化程度”和“用户控制权”比较方案，但需定义评分规则。
