# Product Positioning

Version: 1.0.0

## Purpose
清楚定义产品为谁、解决什么、提供什么不同价值。
## When to Use
Opportunity 已明确，需要形成产品定义或对外/对内定位。
## When NOT to Use
用户和场景未知，或只需要品牌口号时。
## Input
目标用户、场景、Need、竞品、优势、约束和证据。
## Reasoning Process
选择核心用户和场景；定义类别参照；写问题和价值；验证差异化与可信证明；声明边界。
## Output
Positioning Statement、证明点、边界和风险。
## Output Schema
`{"target_user":"","scenario":"","category":"","problem":"","value":"","differentiation":"","reasons_to_believe":[],"boundaries":[]}`
## Quality Criteria
具体、可验证、与策略一致；不使用空泛领先表述。
## Common Mistakes
面向所有人；差异化只是更多功能。
## Example
“为希望快速获得稳定观感但不懂专业参数的电视用户，提供可理解、可预览、可撤回的画质助手”。
