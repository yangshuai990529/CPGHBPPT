# Competitor Analysis

Version: 1.0.0

## Purpose
形成可比的竞品判断和对本产品的 So What。
## When to Use
至少两个竞品或一个竞品与本品有统一比较维度。
## When NOT to Use
不同品类不可比、仅有营销材料、或目标只是收集截图。
## Input
竞品范围、目标用户、场景、证据、比较维度、本品现状。
## Reasoning Process
统一维度；区分宣传与实测；分析定位、能力和交互；识别共同方向与未解决问题；形成 Implication。
## Output
比较矩阵、竞品 Insight、空白和证据限制。
## Output Schema
`{"dimensions":[],"competitors":[],"matrix":[],"common_directions":[],"unresolved_problems":[],"implications":[]}`
## Quality Criteria
维度一致；每格可追溯；结论回答对我们意味着什么。
## Common Mistakes
Feature Checklist 即结论；按品牌逐页没有收敛。
## Example
比较 AI 画质时同时看目标用户、触发场景、自动化程度、可解释性和控制权，而非只看是否有 AI 开关。
